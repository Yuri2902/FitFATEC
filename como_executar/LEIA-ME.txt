FITFATEC — GUIA RÁPIDO PARA EXECUTAR (WINDOWS)
=============================================

REQUISITOS
- Python 3.10 a 3.13; MySQL 8 ou superior; internet na primeira instalação.
- Abra a pasta FitFATEC no VS Code. Execute os comandos no PowerShell,
  na RAIZ do projeto (onde estão configurar.ps1 e iniciar.ps1).

1. PREPARAR O BANCO (SOMENTE NA PRIMEIRA INSTALAÇÃO)
- Inicie o serviço MySQL e conecte-se pelo MySQL Workbench.
- Se o banco fitfatec AINDA NÃO EXISTE, execute bdd/bd_fitfatec.sql.
- Se o banco JÁ EXISTE, NÃO execute esse SQL novamente e NÃO recrie o banco:
  suas contas e fichas podem estar nele. Alterações de estrutura exigem
  backup e atualização específica; peça ajuda ao responsável pelo projeto.

2. CONFIGURAR O PROJETO
No PowerShell, na raiz:

    Set-ExecutionPolicy -Scope Process Bypass
    .\configurar.ps1

O script instala as dependências em ia_academia/.venv, baixa os modelos de voz
Kokoro (aprox. 142 MB) para ia_academia/modelos/kiara_voz e cria um arquivo
.env na raiz, caso ainda não exista. Ele não sobrescreve um .env existente.
Depois que os modelos forem baixados, a voz da Kiara funciona sem internet.
Abra o .env e confira:

    DB_HOST=localhost
    DB_NAME=fitfatec
    DB_USER=root
    DB_PASSWORD=SUA_SENHA_REAL_DO_MYSQL
    GEMINI_API_KEY=SUA_CHAVE_GEMINI  (opcional)

Use os valores reais do seu computador. O script gera automaticamente
uma SECRET_KEY para um .env novo. Nunca envie o .env ao GitHub ou ao grupo.
Sem chave Gemini, os recursos da Kiara ficam mais limitados.

3. INICIAR O FITFATEC
No mesmo terminal, na raiz:

    .\iniciar.ps1

Abra http://localhost:5000 no navegador.
Mantenha o terminal aberto enquanto usa o sistema; Ctrl+C encerra o Flask.
Nas próximas vezes, com tudo configurado, basta iniciar o MySQL e rodar
.\iniciar.ps1. Não é necessário reinstalar o projeto a cada execução.

4. TESTES (OPCIONAL)

    .\testar.ps1

Os testes automatizados não substituem verificar login, Kiara,
treinos e calendário com o MySQL do seu computador.

5. SE ALGO DER ERRADO
- Login ou cadastro falha: confira se o MySQL está ligado e se DB_USER,
  DB_PASSWORD e DB_NAME estão corretos no .env; reinicie o Flask.
- Voz da Kiara indisponível: execute .\configurar.ps1 para instalar o Kokoro e baixar os modelos.
- ModuleNotFoundError: execute .\configurar.ps1 novamente na raiz.
- Script bloqueado pelo PowerShell: execute o comando Set-ExecutionPolicy
  da etapa 2 no terminal atual.
- Página antiga: pressione Ctrl+F5 no navegador.

Para detalhes de instalação, banco existente e funcionamento, leia o README.md
na raiz do projeto.
