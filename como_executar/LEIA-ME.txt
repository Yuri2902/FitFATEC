FITFATEC — COMO EXECUTAR

Este documento descreve como configurar e executar o FitFATEC em outro computador.
Diferencia configuração inicial (primeira vez) de execução diária (já configurado).

--------------------------------------------------------------------------------
1. PRÉ-REQUISITOS (configuração inicial)
--------------------------------------------------------------------------------

- Python 3.9 ou superior
- MySQL 8.0 instalado e em execução localmente
- Acesso a um usuário do MySQL com permissão para criar bancos e tabelas

--------------------------------------------------------------------------------
2. INSTALAÇÃO DE DEPENDÊNCIAS (configuração inicial)
--------------------------------------------------------------------------------

Abra o terminal na pasta `FitFATEC\ia_academia\`:

    python -m venv venv
    venv\Scripts\activate        # Windows
    # source venv/bin/activate   # Linux/Mac

    pip install -r requirements.txt

O `requirements.txt` inclui: flask, pandas, numpy, scikit-learn, joblib, google-genai,
mysql-connector-python.

--------------------------------------------------------------------------------
3. CONFIGURAÇÃO DO BANCO DE DADOS MySQL (configuração inicial)
--------------------------------------------------------------------------------

3.1 Criar o banco e as tabelas

No MySQL Workbench ou cliente de linha de comando, execute o script:

    bdd/bd_fitfatec.sql

ATENÇÃO: o script traz `DROP DATABASE IF EXISTS fitfatec;` COMENTADO no início.
Descomente somente para recriar o banco do zero (apaga todos os dados).
Se o banco já existia de uma versão anterior, recrie-o para receber a coluna
`matricula` e a tabela `agendamento`.

Este script cria o banco `fitfatec` e as tabelas:
  aluno, frequencia, exercicio, treino, agendamento.

A tabela `aluno` inclui as colunas de autenticação: `senha_hash`, `papel`,
`created_at` e `updated_at`.

3.2 Configurar variáveis de ambiente

O `servidor.py` lê as variáveis via `os.environ.get()` e **não carrega**
arquivo `.env` automaticamente. Defina as variáveis no sistema operacional
(não insira senhas reais neste documento):

    DB_HOST=localhost
    DB_NAME=fitfatec
    DB_USER=<seu_usuario_mysql>
    DB_PASSWORD=<sua_senha_mysql>
    SECRET_KEY=<chave_aleatoria_para_sessoes_flask>
    GEMINI_API_KEY=<chave_do_gemini_opcional_para_chatbot>
    GEMINI_MODEL=<modelo_gemini_opcional, padrao gemini-2.5-flash>

No Windows (PowerShell), defina temporariamente na sessão:

    $env:DB_HOST="localhost"
    $env:DB_NAME="fitfatec"
    $env:DB_USER="seu_usuario"
    $env:DB_PASSWORD="sua_senha"
    $env:SECRET_KEY="chave_aleatoria"
    $env:GEMINI_API_KEY="sua_chave_gemini"

Para persistir no Windows, use `setx` (feche e reabrir o terminal depois):

    setx DB_HOST "localhost"
    setx DB_NAME "fitfatec"
    setx DB_USER "seu_usuario"
    setx DB_PASSWORD "sua_senha"
    setx SECRET_KEY "chave_aleatoria"

--------------------------------------------------------------------------------
4. MODELO DE IA (configuração inicial, opcional para risco de desistência)
--------------------------------------------------------------------------------

O modelo de previsão de desistência é gerado a partir de dados fictícios.
Execute apenas na primeira vez ou quando quiser regenerar:

    python gerar_dados.py
    python treinar_modelo.py

Isso cria `dados/alunos.csv` e `modelo_evasao.pkl` na pasta `ia_academia/`.

Sem o modelo, a rota `/api/risco` não funcionará.

--------------------------------------------------------------------------------
5. EXECUÇÃO DIÁRIA (já configurado)
--------------------------------------------------------------------------------

5.1 Ativar o ambiente virtual

    venv\Scripts\activate        # Windows
    # source venv/bin/activate   # Linux/Mac

5.2 Iniciar o servidor Flask

    python servidor.py

O servidor fica disponível em http://localhost:5000

5.3 Verificar se está funcionando

Abra no navegador ou via curl:

    http://localhost:5000/health

Resposta esperada: {"status":"ok","mensagem":"Servidor Flask está funcionando"}

5.4 Acessar a página de teste de autenticação

    http://localhost:5000/teste-auth

Também é possível clicar no botão "Entrar" no canto superior direito da
interface principal (http://localhost:5000/).

A matrícula (ANO + id com 4 dígitos, ex.: 20260001) é gerada no cadastro e
usada no painel "Agendar aula".

A página de teste permite: cadastro, login, consulta de usuário conectado e
logout, consumindo as rotas Flask existentes.

--------------------------------------------------------------------------------
6. EXECUÇÃO DOS TESTES UNITÁRIOS
--------------------------------------------------------------------------------

Na pasta `FitFATEC\ia_academia\`, com o venv ativado:

    python -m unittest test_auth_utils.py test_cadastro.py test_login.py test_session.py test_agendamento.py test_assistente.py -v

Os testes usam mock para módulos externos (assistente e mysql), então
não exigem banco real nem chave de API para serem executados.

--------------------------------------------------------------------------------
7. NOTAS
--------------------------------------------------------------------------------

- O modo debug do Flask fica desligado por padrão; para ligar: FLASK_DEBUG=1.
  Não use em produção.
- O ambiente virtual `venv` não deve ser versionado no GitHub.
- O modelo `modelo_evasao.pkl` e os dados `dados/alunos.csv` são gerados
  localmente e não devem ser versionados.
- Sem `GEMINI_API_KEY`, a Kiara responde em MODO OFFLINE (regras e catálogo de
  treinos), então o protótipo funciona na demonstração mesmo sem internet.
- As senhas de banco e as chaves de API nunca devem ser inseridas neste
  documento nem commitadas no repositório.
