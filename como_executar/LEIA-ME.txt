FITFATEC — INSTALAÇÃO E EXECUÇÃO (ATUALIZADO EM 13/11/2026)
=======================================================

IMPORTANTE: os comandos iniciais são executados na pasta FitFATEC, NÃO em ia_academia.
Requisitos mínimos: Python 3.10+, MySQL 8, Windows PowerShell (scripts opcionais),
internet apenas para instalar dependências/traduzir exercícios/usar Gemini.

A) INSTALAÇÃO RÁPIDA NO WINDOWS
-------------------------------
1. Abra FitFATEC no VS Code e abra um terminal PowerShell na pasta FitFATEC.
2. Execute: .\configurar.ps1
   Isso cria ia_academia/.venv, instala as bibliotecas e cria .env na raiz.
   Se o modelo de demonstração não existir, gera/treina com dados sintéticos.
3. Abra FitFATEC/.env, coloque seu usuário e senha do MySQL.
   O script cria uma SECRET_KEY aleatória ao preparar o arquivo .env.
   Se quiser IA, adicione GEMINI_API_KEY=... (opcional); não exponha essa chave.
4. No MySQL Workbench, se o banco ainda NÃO existe, abra bdd/bd_fitfatec.sql
   e execute UMA vez. Se o banco já existe, NÃO reaplique sem avaliar os dados.
   O script contém CREATE TABLE sem IF NOT EXISTS e reimportar não é migração.
   NUNCA descomente DROP DATABASE sem backup e intenção explícita de apagar dados.
5. Execute: .\iniciar.ps1
6. Abra: http://localhost:5000 (interface) e http://localhost:5000/conta (cadastro/login)
   GET http://localhost:5000/health serve como verificação simples do Flask.

Para rodar testes: .\testar.ps1
Se executar scripts .ps1 for bloqueado, use a alternativa abaixo sem mudar políticas.

B) ALTERNATIVA SEM SCRIPTS / LINUX / MAC
-----------------------------------------
Na pasta raiz FitFATEC:

    python -m venv ia_academia/.venv

Windows PowerShell, sem precisar ativar:
    ia_academia\.venv\Scripts\python.exe -m pip install -r ia_academia\requirements.txt

Linux/Mac:
    ia_academia/.venv/bin/python -m pip install -r ia_academia/requirements.txt

Copie .env.example para .env na raiz e substitua os valores COLOQUE_... .
Crie a SECRET_KEY com:
    python -c "import secrets; print(secrets.token_hex(32))"

No Workbench, importe bdd/bd_fitfatec.sql apenas se necessário.

Se o arquivo ia_academia/modelo_evasao.pkl não existir, execute com o Python
do ambiente virtual:
    cd ia_academia
    python gerar_dados.py
    python treinar_modelo.py
    python servidor.py

Se o modelo já existir, basta iniciar 'python servidor.py' dentro de ia_academia.
No Windows você também pode usar o Python do ambiente por caminho completo
sem executar o activate. A variável .env é lida automaticamente pelo servidor.

C) DEPOIS DA INSTALAÇÃO
-----------------------
No Windows: .\iniciar.ps1, na raiz, e visite http://localhost:5000.
Matrícula é gerada no cadastro e lida pela sessão de login; não deve ser digitada
para agendar aulas. A página /teste-auth continua funcionando como alias antigo
de /conta para preservar favoritos.

D) BIBLIOTECA / GEMINI (OPCIONAIS)
----------------------------------
Já existe um dataset MIT de exercícios em ia_academia/dados/exercicios_mit.json.
Também existe uma pequena seleção de nomes traduzidos. Para preencher MAIS
traduções, configure GEMINI_API_KEY no .env e, na pasta ia_academia, rode:

    python traduzir_exercicios.py
    python traduzir_exercicios.py --conferir

Isso consome chamadas à API; pode ser interrompido e retomado. O arquivo
'ia_academia/dados/revisao_traducoes.csv' precisa de revisão humana, especialmente
para movimentos pouco comuns. Os nomes originais ficam ligados aos mesmos IDs.
Para baixar novamente os metadados da fonte permitida, use:
    python importar_exercicios_mit.py
Mantenha os arquivos de licença e NOTICE do dataset. Não baixe imagens/GIFs.

E) TESTES
---------
Na pasta raiz (Windows): .\testar.ps1
Na pasta ia_academia (com venv ativado):
    python -m unittest discover -s tests -p "test_*.py" -v

Testes usam mocks para serviços externos, mas dependem das bibliotecas Python.
Eles NÃO substituem testes reais com MySQL e com Gemini.

F) SOLUÇÃO RÁPIDA DE PROBLEMAS
------------------------------
- requirements.txt não encontrado: você está na pasta errada. Use instalar pela raiz
  como em (A), ou entre em ia_academia antes de 'pip install -r requirements.txt'.
- 'No such file or directory: traduzir_exercicios.py': entre em ia_academia.
- 'Access denied' no MySQL: confira DB_USER/DB_PASSWORD no .env, serviço ativo
  e privilégios no banco fitfatec.
- 'Table already exists': não execute o SQL de criação novamente em banco existente.
- Flask sem rota ou sem CSS após alteração: reinicie o servidor e pressione Ctrl+F5.
- Kiara em modo offline: confira GEMINI_API_KEY no .env, internet, modelo e cotas da API.
- 'ModuleNotFoundError': repita .\configurar.ps1; não use Python global por engano.
- 'InconsistentVersionWarning' em modelo_evasao.pkl: copie seu modelo como backup
  e, com o venv ativo em ia_academia, execute gerar_dados.py e treinar_modelo.py
  para recriar SOMENTE o modelo sintético com a versão local do scikit-learn.
- Arquivos antigos em venv/, .git/ e __pycache__/ NÃO devem ser copiados
  do computador de outra pessoa; são locais e recriáveis.

G) OBSERVAÇÕES
-------------
- O app.py é um protótipo alternativo Streamlit; não é necessário para Flask.
  Para utilizá-lo, instale 'pip install -r requirements-streamlit.txt' e execute
  'streamlit run app.py' a partir de ia_academia.
- FLASK_DEBUG=1 apenas no desenvolvimento; nunca em produção.
- Um servidor Flask local não é hospedagem de produção nem substitui segurança
  de deploy. O banco MySQL e os agendamentos exigem testes de integração.
- Não versionar .env, API keys, credenciais nem arquivos locais de usuário.
